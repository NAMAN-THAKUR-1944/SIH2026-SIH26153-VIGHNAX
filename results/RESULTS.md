# Benchmark results

Generated by `python evaluate.py` from `models/world_model.pt`. Window = 10 s, context = 18 windows, forecast horizon K = 6 windows (60 s). One model is trained on all datasets; every test source (day, capture, time slice or botnet family) is unseen in training.
F1 / FPR use each model's operating threshold, chosen per dataset on that dataset's validation split only (highest detection with at most 5% false alarms on validation, same rule for both models; i.e. per-site calibration). AUROC is threshold-free. WM = world model, LR = logistic-regression baseline on the same features.
